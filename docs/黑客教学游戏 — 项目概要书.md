# 黑客教学游戏 — 项目概要书

2026-09-20 · @Someone

这是一款在 Steam 上分发、Windows / macOS / Linux 多端运行的黑客题材教学游戏：玩家在游戏内操作真实的 Linux 虚拟机与虚拟网络，通过一段世纪末黑客剧情，学会真实的命令行、网络与安全知识。

## 这是什么

它是一款把真实 Linux 操作包装进游戏的教学产品。玩家操作的不是脚本化的假终端，而是跑在 QEMU 里的真实系统和一个真实的虚拟网络，所以在游戏里学会的命令、网络配置和安全原理，拿到真实机器上就能用。游戏化的剧情和成长系统负责提供动机和沉浸感，硬核的真实性负责保证学到的是真东西。

剧情前提：一个传奇黑客随身的 U 盘里装着多个系统和工具，辗转流落到主角手中。主角插上 U 盘，逐步揭开世纪黑客争斗与未来黑客逃亡的真相。这个设定既是叙事引擎，也让「手里的工具碾压这个时代」成为可玩的爽感来源。

主角的系统成长线对应着能力台阶：开局是一台只有 FreeDOS 的老机器，制造「我需要一个真正的系统」的动机；随后借助 U 盘，可以换成 Alpine（轻量、工具丰富的现代 Linux）或 FreeBSD（另一种 Unix 传统）。目标机器则是遍地的老旧小型 Linux。系统不再只是背景，而是玩家实力与世界技术演进的同一条线。

## 技术选型

核心原则贯穿全部选择：把复杂度尽量放在完全掌控的 Godot 前端，让后端虚拟机保持小而纯。明确排除 v86、容器、真实 exploit / 攻击框架、Kali——出于分发体积、杀软误报和许可证考虑。

| 层 | 选型 | 关键理由 |
| --- | --- | --- |
| 前端引擎 | Godot 4 + C# | 三端桌面支持好；C# 是熟练语言，交换机 / 控制 / 关卡逻辑都用它 |
| 虚拟机 | QEMU，TCG 为性能基准 | 不要求 VT-x、不进 BIOS，兑现「多端易运行」承诺；有硬件加速则作为额外收益 |
| 终端 | godot-xterm（原生节点） | 内部已含 ANSI 解析渲染；串口裸字节直连，不需要 libvterm 中间层 |
| 虚拟网络 | 自研 C# 交换机 + QEMU `-netdev stream` | 用户态、免权限；同时是流量检测与可视化的唯一入口 |
| 任务判定 | 隐藏第二串口 / guest-agent | 检测客户机真实状态，玩家绕不过 |
| 主角镜像 | Alpine（现代）、FreeBSD（另一 Unix 传统）、FreeDOS（开局） | 对应系统成长线；apk 可把工具烤进 Alpine 镜像 |
| 目标镜像 | 极小 Buildroot Linux | 几 MB，多台共享，对应遍地的老旧机器 |

## MVP 做什么

第一个 MVP 只验证一件事：技术脊椎能不能端到端跑通，不做剧情、美术和游戏内容。目标是「两台真实虚拟机在 Godot 里被启动、各有可用终端、通过自研虚拟网络互相 ping 通、并被游戏自动判定完成」。

它要做到、且仅做到：

1. Godot 全程用 TCG 启动两台虚拟机——主角机跑 Alpine（顺便验证 vim/tmux 渲染），目标机跑极小 Buildroot；不要求玩家改任何系统设置。
2. 每台机器的串口各连一个 godot-xterm 终端面板，玩家能正常敲命令、看输出。
3. 两台机器通过 `-netdev stream` 接入同一个 C# 虚拟交换机组成虚拟局域网。
4. 配好 IP 后，一台能 `ping` 通另一台，真实以太网帧经过交换机转发。
5. 隐藏控制通道检测到「ping 成功」，向 Godot 发出「任务完成」信号并给最简反馈。
6. 在 Alpine 终端里跑通 vim 和 tmux（含分屏），确认 ANSI 渲染、`TERM` 设置、resize 转发都正确。

做到这六条，就意味着 QEMU 编排、裸字节终端、终端渲染、用户态虚拟网络、任务判定五个环节全部端到端验证通过，且需在 Windows、macOS、Linux 三端都能稳定重现。这一步跑通，项目就从「设想」变成「可落地」，之后才进入往脊椎上盖内容的阶段。
